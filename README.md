## Overview

A simple web application. Shows my learning path through:
* REST API development using Spring Boot, 
* data modeling with JPA and Hibernate (no manual SQL scripts required),
* PostgreSQL database integration (H2 database for testing purposes). 

## Features

* JPA and Hibernate data modelling,
* RESTful endpoints,
* SpringBoot dependency injection.
